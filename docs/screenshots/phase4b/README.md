# Phase 4B: the new frame

For the designer: AI-Editor's own window after Phase 4B (0.39.0), built from
`mockups/` (theme.css is used as it is: `ai_editor/app/frame/theme.css`).

| File | What it shows |
|---|---|
| `frame-library-dark.png` | Library, dark: sidebar with counts, header line, the morning note, the Jobs panel open (finished, running with time and steps, waiting) |
| `frame-library-light.png` | The same, light |
| `frame-clips-dark.png` | Clips, Jobs panel closed to its strip: today's Clips screen inside the frame, player on top, list below at full width |

The **Auto · Light · Dark** switch at the foot of the sidebar is new: the
creator wanted a choice that stays, whatever Windows is set to. It uses the
mockups' `.seg` control.

**The data is made up** (a demo library): no real streams, names or folders.

The body is still today's screen for each item, shown inside the frame without
its own title, Jobs box and tabs; each is rebuilt in the new design from 4C on.
Differences from the mockups so far: the Jobs panel has a close button (**›**)
at its top, as finished jobs stay until cleared; the overnight card shows what
overnight work really does (it never frees or deletes files).
