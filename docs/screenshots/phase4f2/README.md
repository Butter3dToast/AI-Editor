For the designer: the rest of Review's tabs from `mockups/Review.dc.html` (0.44.0), drawn by
the window itself. Publish and a Let's Play's Part Planner follow in 4F-3. The sidebar
still says 0.43.0: the pictures were taken just before the version changed.

**The data is made up** (a demo library): no real streams, names or folders. The
picture is a test pattern standing in for a stream's preview copy, and the words are
invented for the picture.

What differs from the mockups, and why:

- **Tabs, not a fold**, as in 4F-1 (the creator's choice).
- **Burn in captions is kept with each plan** (the creator's choice): ticking it for one
  video doesn't tick it for the next. Off unless ticked, like every effect.
- **The suggested effects are listed one moment per row**, each unticked: nothing is used
  until the creator ticks it.
- **Render opens a panel first** (the creator's choice) that says what the video will
  have, so a forgotten tick is seen before a render of several minutes.
- **A Let's Play** has no effects or Between clips (the creator's Phase 2 choice), and no
  caption lines to fix one by one; its tabs say so instead of looking empty.
- **The Library's Game box** is new (1 Nov): a recording named only by its date came in
  with no game, so it counted as a stream.
